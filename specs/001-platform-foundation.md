# 001 — Platform Foundation

## Goal

Establish the repository foundation and folder skeleton for Albert. No app
logic, no auth, no Dockerfiles, no database code yet.

## Scope

In scope:

- Root project files (README, CONTRIBUTING, OWNERSHIP, env example, ignore files,
  Makefile, placeholder docker-compose).
- Folder skeleton for backend, admin, modelserver, guardrails, widget, scripts,
  docs, specs, tests, and CI.
- Placeholder docs, PR template, and placeholder CI workflow.

Out of scope (later phases):

- Application code and services.
- Auth and tenancy logic.
- Dockerfiles and database code.

## Outcome

A runnable foundation that the team can build on, with clear ownership and
contribution rules.
