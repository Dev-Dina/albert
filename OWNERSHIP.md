# Ownership

The project lead owns the protected foundation files.

## Protected Files

Do not edit these without review:

- `docker-compose.yml`
- `.env.example`
- `Makefile`
- `backend/app/core/config.py`
- `backend/app/core/security.py`
- `backend/app/core/logging.py`
- `backend/app/db/session.py`
- `.github/workflows/ci.yml`

Teammates should not edit protected files without review.

## Later Ownership Areas

- Platform / Auth / Tenancy
- RAG / Agent / Memory
- Modelserver / Guardrails / Security
- Widget / Admin / CI support
